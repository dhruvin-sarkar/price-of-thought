# The Price of Thought

Wiring cost and the brain–nerve cord connective in the complete *Drosophila* male central nervous system connectome.

This repository tests whether the placement of cell types in the male CNS (`male-cns:v1.0`, Berg et al., *Cell* 2026) minimizes physical wiring cost, and whether the long, unavoidably expensive connections of the neck connective, carried by descending and ascending neurons, are reserved for highly connected cell types in the way hub-to-hub connections are in mammalian connectomes.

It is the third part of a three-part study of the same connectome, after [ConnectomeLens](https://github.com/dhruvin-sarkar/ConnectomeLens) and [Fault Lines](https://github.com/dhruvin-sarkar/fault-lines).

Work in progress.
